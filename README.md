# 🔐 User Login & Registration Page

A responsive **User Login and Registration System** built using **HTML5, CSS3, and JavaScript**. This project provides a clean and modern authentication interface with client-side form validation for an improved user experience.

---

## ✨ Features

### 🔑 Login Page

- User-friendly login form
- Email and password authentication fields
- Client-side form validation
- Responsive design
- Error message handling

---

### 📝 Registration Page

- Create a new user account
- Full Name input
- Email validation
- Password validation
- Confirm Password validation
- Password strength requirements
- Responsive layout

---

### 🎨 User Interface

- Modern and clean design
- Mobile-friendly responsive layout
- Interactive form animations
- Input focus effects
- Consistent styling
- Easy-to-use interface

---

### ✅ Form Validation

JavaScript validation includes:

- Required field validation
- Valid email format
- Password length validation
- Password confirmation matching
- Real-time error messages
- Prevent submission of invalid forms

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
